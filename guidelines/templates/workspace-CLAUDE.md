# AliceUT workspace

Parent folder of four sibling repos: `aliceut-ecom-document` (specs, conventions, guidelines), `aliceut-ecom-backend`, `aliceut-ecom-frontend`, `aliceut-ecom-infra`. This folder is not a git repo. Agent worktrees live in `wt/`, never inside a repo directory.

The document repo's CLAUDE.md is the base knowledge for every session started here. It carries the spec-is-canonical rule, the money and event rules, the subagent routing and review gate, and the required-reading table for `conventions/`. Do not start work before reading it and the files it imports.
